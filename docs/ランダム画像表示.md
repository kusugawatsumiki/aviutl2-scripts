
# ランダム画像表示

指定された複数の画像をランダムに連続表示します。

## パラメータ

### 画像パターン

| パラメータ名 | 説明 |
| --- | --- |
| `画像パターン` | ランダム表示させたい画像ファイル。最大8つまで指定可能です。 |

### 位置

| パラメータ名 | 説明 |
| --- | --- |
| `X座標ランダム幅` | 画像表示時のX座標のランダム幅。 |
| `Y座標ランダム幅` | 画像表示時のY座標のランダム幅。 |

### 依存パラメータ

| パラメータ名 | 説明 |
| --- | --- |
| `モード` | `フレーム数` または `BPM` から選択。 |
| `フレームレート` | プロジェクトのフレームレート。 |
| `フレーム数` | （`モード` が `フレーム数` のときのみ有効）画像切替を何フレームごとに行うか。数字を大きくするほど切替速度がゆっくりになります。 |
| `BPM` | （`モード` が `BPM` のときのみ有効）画像切替を行うBPM。 |
